# Борт#1 (учёт поездок)

Android-приложение для учёта поездок на своей машине: км, время и стоимость
топлива за поездку, неделю, месяц. Все данные — только в телефоне.

План и устройство — в [docs/PLAN.md](docs/PLAN.md).

## Как получить приложение на телефон

APK собирается автоматически на серверах GitHub (бесплатно), компьютер не нужен.

1. Откройте на телефоне страницу репозитория → **Releases** → **Последняя версия**.
2. Скачайте **Poezdki.apk** и откройте его.
3. Установите (на Samsung: если блокирует — **Настройки → Безопасность и
   конфиденциальность → Автоблокировщик** выключить на время установки).

Новая версия ставится **поверх** старой — поездки сохраняются.
Не удаляйте приложение: вместе с ним удалятся все поездки.

## Разрешения (Samsung: Настройки → Приложения → Поездки)

| Что | Где включить | Зачем |
|---|---|---|
| Местоположение → **Разрешить в любом режиме** | Разрешения → Местоположение | запись идёт, когда открыт Google Maps и погас экран |
| **Уведомления** | Уведомления | без них Android не показывает «Идёт запись поездки» |
| Аккумулятор → **Без ограничений** | Аккумулятор | чтобы Samsung не обрывал запись |

## Один раз: ключ подписи

Ключ нужен, чтобы каждая новая версия вставала поверх старой.

1. **Settings → Secrets and variables → Actions → New repository secret**:
   имя `SIGNING_PASSWORD`, значение — 24+ латинских букв и цифр
   (без пробелов и других знаков). Сохраните пароль у себя: без него
   новые версии собрать нельзя.
2. **Actions → Create signing key (one-time) → Run workflow**.
