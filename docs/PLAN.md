# Поездки — план (этап 0)

## Решения
- **Kotlin + Jetpack Compose**, сборка APK на GitHub Actions (бесплатно, без лимита сборок).
  Expo не используем: кнопка «Стоп» в уведомлении и автозапись (этап 2) всё равно требуют Kotlin.
- Идентификатор приложения: `io.github.aleks007k.poezdki` — **не менять никогда**.
- Минимальная версия Android — 8.0 (API 26).

## Экраны
```
Первый запуск: Расход и цена → Местоположение → «В любом режиме» → Уведомления → Батарея
ГЛАВНЫЙ:  [ Куда ________ ] [ ➤ ]
          [  Дом  ] [ Работа ] [ Своё место ]
                 Итоги
ПОЕЗДКА:  87 км  ·  1 ч 05 мин  ·  [ СТОП ]
ИТОГИ:    [Неделя|Месяц]  ‹ 12–18 окт. ›
          км · поездок · €
          карточки поездок (нажать — удалить)
          Расход → [л/100 км] [€/л]
```

## Данные (только в телефоне, SQLite)
- `trips` — поездки: время, точки начала/конца, адреса, км, расход и цена на момент поездки.
- `points` — точки GPS текущей поездки (после конца удаляются).
- `places` — три кнопки: название, адрес, координаты.
- Настройки (расход, цена) — SharedPreferences.

## Начало и конец поездки
Все пороги — в `Config.kt`. Логика — в `TripTracker.kt` (покрыта тестами).
- Начало — нажатие стрелки или кнопки места.
- Стою = скорость < 8 км/ч. Рядом с целью (200 м) 2 минуты — конец.
  В другом месте 10 минут — пауза, ещё 30 минут ждём: быстрее 25 км/ч — продолжение.
- Конец поездки — момент остановки. Ожидание и ходьба не считаются.
- Отсев GPS: точность хуже 30 м, сдвиг < 10 м (дрожание), «прыжки» быстрее 250 км/ч.

## Риски
- Экономия батареи (Samsung, Xiaomi) может оборвать запись, если не выбрать «Без ограничений».
- В туннелях GPS пропадает — участок считается по прямой.
- Геокодер телефона может не работать на телефонах без сервисов Google — тогда адрес «…».
- С 2027 года Google вводит проверку разработчиков для установки APK.

## Google Play позже
- Фоновое местоположение — отдельная проверка (видео + политика конфиденциальности).
- Аккаунт разработчика $25; закрытый тест 12 человек × 14 дней.
- Не используем: окно поверх приложений, прямой запрос отключения оптимизации батареи.

## Принципы интерфейса (просьба владельца — соблюдать всегда)
- **Минимализм:** на экране только то, чем пользуются. Никаких пояснительных абзацев —
  подпись в 2–4 слова; объяснения — в ответе владельцу, не в приложении.
- **Интуитивно:** понятно без инструкции; узнаваемые значки (иконки приложений, шестерёнка);
  одна строка = одно действие.
- Не всплывать с разрешениями и окнами неожиданно — только по нажатию пользователя.
- Технические подробности (диагностика, «последний сигнал») — не показывать.
