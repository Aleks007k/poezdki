# Шрифты

В приложение встроены два бесплатных шрифта Google Fonts (лицензия SIL Open Font License 1.1 —
можно встраивать в приложения, в том числе платные):

- **Unbounded** — цифры и заголовки. https://github.com/googlefonts/unbounded
- **Manrope** — обычный текст. https://github.com/sharanda/manrope

Файлы `app/src/main/res/font/*.ttf` — отдельные начертания, нарезанные из
переменных шрифтов репозитория google/fonts.
